# Stock Portfolio Management Application
This is a local application that enables users to build and manage their stock portfolios using real-time stock data. The program fetches data from the Alpha Vantage API and provides an intuitive interface for portfolio management.

## Features:
 - Real-time Stock Data: Fetch the latest stock prices and other details.
 - Portfolio Management: Add, update, and track your stock investments.
 - Local Storage: Save your portfolio data locally and securely on your machine.

## Prerequisites:
 - Java Development Kit (JDK): Ensure JDK 18 or higher is installed.
 - Alpha Vantage API Key: Register at Alpha Vantage to obtain a free API key.

## Usage:
 - Navigate to the res folder and read the SETUP_README.txt for information on how to run this application
